# Security

## Reporting a problem

Please report security problems privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue. You will get an answer within a week.

Include what you found, how to reproduce it, and which version (`krnl0 version`).

## Supported versions

Only the newest release gets fixes. Update with `docker compose pull && docker compose up -d` or by running the installer again.
