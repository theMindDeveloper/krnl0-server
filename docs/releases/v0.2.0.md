# KRNL0 server 0.2.0

One-click updates from the KRNL0 app, and Docker in one command.

**Step by step, with pictures:** [theminddev.com/krnl0/server.html](https://theminddev.com/krnl0/server.html)

## New

- **One-click updates.** In the KRNL0 app (0.14 or newer), click **saved** in the top bar, then **Update server**, and type your password. The updater installs only signed releases of this repository, makes a backup first, checks the new version, and goes back by itself if anything fails. On the server: `krnl0 update` and `krnl0 update now`.
- **Update by itself at night** (04:00 server time), off unless you turn it on: in the app, the installer, or `krnl0 update auto on`.
- **Docker in one command**, with the updater included:
  - Linux and Mac: `curl -fsSL https://github.com/theMindDeveloper/krnl0-server/releases/latest/download/docker.sh | sh`
  - Windows (PowerShell): `irm https://github.com/theMindDeveloper/krnl0-server/releases/latest/download/docker.ps1 | iex`
  - A server you started with `docker run` moves over with its data, port, address and time zone.
- **Linux:** `install.sh` now adds the updater (`krnl0-update.path`, `.service`, `.timer`).

## Updating from 0.1.0

0.1.0 can't update itself yet, so this one update is by hand; from then on it is one click.
- **Docker:** run the one command above. It keeps your data.
- **Linux:** run the install command again: `curl -fsSL https://github.com/theMindDeveloper/krnl0-server/releases/latest/download/install.sh | sh`

## Safe by default

- The updater trusts one thing: a release of this repository signed by its own release workflow at that exact tag, pulled by the image digest in the signed `release.json`. The server itself can only ask for an update, never choose what is installed.
- Every update and the night switch need your password (and 2FA code), with the login limits.
- The data volume is external: `docker compose down -v` never deletes your boards.

## Check the download

`SHA256SUMS` lists every file and is signed with Sigstore (bundle v0.3), and so is the image.

```sh
cosign verify-blob --new-bundle-format --bundle SHA256SUMS.sigstore.json \
  --certificate-identity-regexp '^https://github.com/theMindDeveloper/krnl0-server/\.github/workflows/release\.yml@refs/tags/v' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing
```
